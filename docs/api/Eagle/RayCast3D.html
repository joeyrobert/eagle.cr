    class Eagle::RayCast3D

    • Eagle::RayCast3D
    • Eagle::Node3D
    • Eagle::Node
    • Reference
    • Object

    Overview

    Casts a ray from the node toward #target every physics step. Use it for ground checks, line of sight and hit-scan weapons.

    Defined in:

    eagle/nodes/physics3d_nodes.cr
