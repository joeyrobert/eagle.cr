    class Eagle::Button

    • Eagle::Button
    • Eagle::Control
    • Eagle::Node2D
    • Eagle::Node
    • Reference
    • Object

    Overview

    A clickable button. Connect to #pressed, or pass a block to the constructor.

    start = Button.new("Start") { puts "go" }
mute = Button.new("Mute")
mute.toggle_mode = true
mute.on_toggled { |on| Audio.bus("music").muted = on }
