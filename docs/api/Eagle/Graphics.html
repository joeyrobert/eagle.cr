    class Eagle::Graphics

    • Eagle::Graphics
    • Reference
    • Object

    Overview

    Immediate-mode 2D drawing (LÖVE-style), batched into as few draw calls as possible. Coordinates are in logical points with (0,0) top-left.

    Defined in:

    eagle/graphics/graphics.cr

    Constant Summary

    VERTEX_FLOATS = 8
